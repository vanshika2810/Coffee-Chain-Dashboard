# ☕ Coffee Chain Sales Dashboard

## 📌 Overview

The Coffee Chain Sales Dashboard is an interactive Business Intelligence project developed using Power BI and Tableau to analyze sales performance, profitability, market trends, and product demand across multiple regions. The dashboard transforms raw business data into actionable insights through interactive visualizations, helping stakeholders make informed business decisions.

---

## 🚀 Features

* Interactive sales dashboard
* Revenue and profit analysis
* Product performance tracking
* Customer trend analysis
* Regional sales insights
* KPI monitoring and reporting
* Data-driven business visualization
* Interactive Tableau dashboard access
